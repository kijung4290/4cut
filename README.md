# 우리의 네컷

브라우저 카메라로 사진을 찍고 네 장을 골라 기관 로고가 포함된 세로형 네컷 JPG를 만드는 웹앱입니다.

## 실행

```bash
npm install
npm run dev
```

카메라는 보안상 `localhost` 또는 HTTPS 환경에서만 동작합니다.

## 전송 방식

- 문자: 메세지미 MMS API를 통해 원본 1:3 네컷 비율을 유지한 JPG를 직접 전송합니다.
- 메일: Web Share API를 통해 생성된 JPG를 설치된 메일 앱으로 전달합니다.
- 데스크톱 또는 공유 미지원 브라우저: JPG를 내려받아 직접 첨부할 수 있도록 자동 전환합니다.
- 문자 전송 시에만 압축된 전송용 JPG가 서버에 임시 저장되며, 24시간이 지난 파일은 다음 전송 시 자동 삭제됩니다.

## 메세지미 설정

`.env.example`을 `.env`로 복사한 뒤 API 키, 사전 등록한 발신번호, 실제 배포 주소를 입력합니다. `PUBLIC_BASE_URL`은 메세지미 서버가 사진을 가져갈 수 있는 외부 HTTPS 주소여야 하므로 `localhost`는 사용할 수 없습니다.

## Vercel 배포

1. Vercel에서 이 GitHub 저장소를 가져옵니다.
2. 프로젝트의 Storage에서 Public Vercel Blob 저장소를 생성해 연결합니다.
3. Environment Variables에 `MESSAGEME_API_KEY`, `MESSAGEME_CALLBACK`을 등록합니다.
4. 다시 배포합니다. `BLOB_READ_WRITE_TOKEN`은 Blob 연결 시 자동 등록됩니다.

Vercel에서는 `/api/send-mms` Function이 완성된 JPG를 Blob에 올린 뒤 메세지미 MMS API에 공개 이미지 주소를 전달합니다.

## 주요 기능

- 전·후면 카메라 전환 및 3초 카운트다운 촬영
- 카메라 화면에서 사람 옆에 움직이며 사진에도 합성되는 GIF 캐릭터
- 기기 사진 여러 장 불러오기
- 촬영본 중 네 장 선택 및 순서 지정
- 4종 프레임 템플릿
- 기관명 및 기관 로고 삽입
- 고화질 JPG 생성·저장·공유

## 화면 주소

- 일반 촬영 화면: `/`
- 템플릿 관리자 화면: `/admin`

관리자 화면에서 프레임 색상, 배경 이미지와 선명도, 기관명, 하단 문구, 로고를 저장한 뒤 촬영 화면으로 이동하면 저장한 설정이 자동 적용됩니다. 설정은 현재 브라우저에 저장됩니다.

촬영 GIF도 관리자 화면에서 교체하거나 숨길 수 있습니다. GIF 애니메이션을 유지하기 위해 원본 파일을 그대로 저장하며, 브라우저 저장 공간을 고려해 2MB 이하 파일을 지원합니다. GIF는 카메라 화면 오른쪽에서 움직이고 셔터를 누르는 순간의 프레임이 사진에 합성되어 완성된 네컷 JPG에도 포함됩니다. 자연스러운 합성을 위해 배경이 투명한 GIF를 권장합니다.
